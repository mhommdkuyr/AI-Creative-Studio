# Anime Episode 01 — تحدّي القوة

The multi-character episode preset is stored in `episode-01-challenge-of-power.json`. It contains three character tracks, more than 50 transform keyframes, six timed shots and Arabic dialogue timings. The full rendered MP4 and authoring package are delivered separately as `episode-01-animation-engine-package.zip`.

**Render profile:** 25 seconds, 960×540, H.264 video, stereo AAC. The motion pass renders 300 source frames at 12fps and frame-blends intermediate frames for a 24fps / 600-frame delivery stream. Motion is generated by interpolating character transforms each frame and drawing motion trails, colored energy arcs, particle sparks, impact rings, camera zoom/shake and a timed score.

**Current scope:** the episode uses 2D cutout sprites from the supplied character sheet. Their whole-body transforms are animated; this first version does not yet have full per-joint skeletal deformation or professional Arabic voice acting. Subtitles are Arabic RTL and the voice clips are locally synthesized.
